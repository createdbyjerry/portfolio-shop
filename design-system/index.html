Foundations

How the Tokens Are Layered

Three tiers, so a brand change is one edit and a new theme is one file.

Tier 01 · core

Raw values

tokens/base.json. Hex codes, pixel sizes, font stacks. Named for what they are (color.coral.500), never for where they're used.

Tier 02 · semantic

Meaning

tokens/themes/perigee.json. Aliases like text.secondary → {color.neutral.400}. The site's CSS reads these.

Tier 03 · component

Overrides

Same theme file, under component. --button-bg, --card-border. Change one component without touching the rest.

Workflow

Edit a JSON file, run npm run tokens (or npm run tokens:watch while you work). It regenerates assets/css/tokens.css and the data this page renders from. To add a theme, copy perigee.json, set its selector to [data-theme="name"], and change only the aliases.
