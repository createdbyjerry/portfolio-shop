Design System

Two themes, Perigee (dark) and Apogee (light), and every component the site is built from. You are viewing Perigee; flip the sun / moon switch in the bottom-right corner to compare. This page is unlisted: it isn't in the nav or sitemap and asks search engines not to index it.

Foundations

How the Tokens Are Layered

Three tiers, so a brand change is one edit and a new theme is one file.

Tier 01 · core

Raw values

tokens/base.json. Hex codes, pixel sizes, font stacks. Named for what they are (color.coral.500), never for where they're used.

Tier 02 · semantic

Meaning

tokens/themes/perigee.json. Aliases like text.secondary → {color.neutral.400}. The site's CSS reads these.

Tier 03 · component

Overrides

Same theme file, under component. --button-bg, --card-border. Change one component without touching the rest.

Workflow

Edit a JSON file, run npm run tokens (or npm run tokens:watch while you work). It regenerates assets/css/tokens.css and the data this page renders from. To add a theme, create tokens/themes/name.json, set its selector to [data-theme="name"], and list only the tokens it changes. apogee.json is the example: 28 colour overrides, nothing else. The build fails if an override points at a path the default theme doesn't have.

Themes

Perigee & Apogee

Perigee is the dark default: the eclipsed orb at its closest. Apogee is the light theme: white surfaces, near-black ink, and the coral and gold stepped down until they read on white. Both sides of every pair below were measured; all body text in Apogee clears AAA (7:1).

Switching & rememberingassets/js/site.js
01 · before paint

No flash

A one-line script in every page's <head> reads localStorage["cbj-theme"] and sets data-theme on <html> before the CSS paints.

02 · on click

Saved

The switch stores "light" or "dark", updates aria-checked and the browser theme-color, and syncs other open tabs.

03 · listeners

cbj:themechange

Fired on window after every switch. The orb listens and eases to the new theme's --orb-* colours.
